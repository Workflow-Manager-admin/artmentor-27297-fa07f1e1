# ArtMentor Features Directory

This folder contains the main ArtMentor app features/components, each in its own subfolder:

- `DrawingCanvas` – The main canvas for users to create drawings and receive AI feedback.
- `AIAssistant` – The right panel for AI-powered instructions, suggestions, and chat.
- `Lessons` – The sidebar for lesson navigation and step-by-step guidance.
- `Progress` – An area for showing progress tracking, stats, or suggestions.

Each feature is scaffolded with a placeholder file and detailed comments to ease future development.

All feature entrypoint components are directly imported in `App.js`.
